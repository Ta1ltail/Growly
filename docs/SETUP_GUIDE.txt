############################################################
#                                                          #
#   PROJECT 101 - SETUP GUIDE (Windows)                    #
#   Step-by-step: install tools + create the project       #
#                                                          #
############################################################

Follow this top to bottom. Do NOT skip steps.
After each install, OPEN A NEW terminal so it picks up changes.


==========================================================
 PART 1 - INSTALL THE TOOLS (one time only)
==========================================================

-----------------------------------------
 1.1  Node.js  (runs everything)
-----------------------------------------
  - Go to:  https://nodejs.org
  - Download the "LTS" version (the left, recommended button)
  - Run the installer. Click Next / accept defaults the whole way.
  - IMPORTANT: leave "Add to PATH" checked (it is by default).
  CHECK IT WORKED:
    Open PowerShell and type:
        node -v
        npm -v
    You should see version numbers (e.g. v22.x.x). If yes -> done.

-----------------------------------------
 1.2  Git  (saves versions of your code)
-----------------------------------------
  - Go to:  https://git-scm.com/download/win
  - Download and run the installer.
  - Accept defaults (just keep clicking Next). It is safe.
  CHECK IT WORKED:
    In a NEW PowerShell window:
        git --version
    You should see a version number.

  THEN set your name/email (used to label your saves):
        git config --global user.name "Justin"
        git config --global user.email "your-email@example.com"

-----------------------------------------
 1.3  VS Code  (where you write code)
-----------------------------------------
  - Go to:  https://code.visualstudio.com
  - Download for Windows, run installer.
  - IMPORTANT: tick the boxes:
        [x] Add "Open with Code" to file context menu
        [x] Add to PATH
  - Open VS Code, then install these extensions (left sidebar,
    the squares icon, search each name, click Install):
        * ESLint
        * Prettier - Code formatter
        * Tailwind CSS IntelliSense
        * (later) Supabase

-----------------------------------------
 1.4  GitHub account  (online backup of your code)
-----------------------------------------
  - Go to:  https://github.com  -> Sign up (free)
  - Remember your username + password. We use it later.


==========================================================
 PART 2 - CREATE THE PROJECT
==========================================================

-----------------------------------------
 2.1  Open your dev folder in a terminal
-----------------------------------------
  - Open PowerShell, then type:
        cd C:\Users\Justin\dev
  (This is your projects home. The new app will be created here.)

-----------------------------------------
 2.2  Create the Next.js app
-----------------------------------------
  Type this ONE command (it sets up the whole pro foundation):

      npx create-next-app@latest lifegrid --typescript --tailwind --eslint --app --src-dir --import-alias "@/*"

  - If it asks "Ok to proceed?" -> press Enter (y).
  - If it asks "Use Turbopack?" -> Yes.
  - Wait 1-2 minutes while it installs.
  This creates a folder:  C:\Users\Justin\dev\lifegrid

-----------------------------------------
 2.3  Open the project in VS Code
-----------------------------------------
      cd lifegrid
      code .

-----------------------------------------
 2.4  Run it (see it live in your browser)
-----------------------------------------
  In VS Code, open the terminal (menu: Terminal -> New Terminal),
  then type:
      npm run dev
  Open your browser to:  http://localhost:3000
  You should see the starter page. THAT MEANS IT WORKS.

  To stop the server: click the terminal, press Ctrl + C.


==========================================================
 PART 3 - WHAT THE PROJECT FOLDER LOOKS LIKE
==========================================================
  lifegrid/
    src/
      app/          <- your PAGES live here (Today, Tracker, etc.)
        page.tsx        the home page
        layout.tsx      the wrapper around every page
      components/    <- reusable pieces (buttons, the grid, cards)
      lib/           <- helper code (database, utils)
    public/          <- images, icons, logo
    .env.local       <- SECRET keys (NEVER share / never commit) *
    package.json     <- list of installed tools
    next.config.js   <- app settings
    .gitignore       <- files Git should ignore (already correct)

  * .env.local is created by YOU later for Supabase/payment keys.
    It is already in .gitignore so it stays private. Good.


==========================================================
 PART 4 - SAVE TO GITHUB (first backup)
==========================================================
  (create-next-app already ran "git init" for you)
  1. On github.com -> click "+" -> New repository
       name: lifegrid   | keep it Private | DO NOT add a readme
       -> Create repository
  2. Copy the commands GitHub shows under
     "...or push an existing repository", they look like:
        git remote add origin https://github.com/YOURNAME/lifegrid.git
        git branch -M main
        git add .
        git commit -m "first commit"
        git push -u origin main
  3. Paste them in the VS Code terminal. Your code is now backed up.


==========================================================
 PART 5 - DONE? CHECKLIST
==========================================================
  [ ] node -v  shows a version
  [ ] git --version  shows a version
  [ ] VS Code installed + extensions added
  [ ] GitHub account made
  [ ] lifegrid project created
  [ ] npm run dev  shows the page at localhost:3000
  [ ] code pushed to GitHub

  WHEN ALL CHECKED -> tell Claude "setup done"
  and we start Phase 1: the data shape + Today page.
