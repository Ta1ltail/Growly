Improve the entire UI/UX and system logic of the Habit Tracking Web Application. Think like a senior product designer, UX designer, and software architect. Focus on usability, anti-cheat mechanics, scalability, and a premium user experience.

### Core UI/UX Improvements

* Reduce excessive page scrolling throughout the application.
* Use fixed-height containers with internal scrolling and pagination where appropriate.
* Design the interface for desktop/web-first usage.
* Improve spacing, visual hierarchy, responsiveness, and accessibility.
* Create a cleaner, more modern, premium dashboard experience.

### Navigation & Structure

Create dedicated sections/pages for:

* Dashboard
* Today
* Habits
* Tracker
* Calendar
* Goals
* Templates
* Statistics
* Notes
* Habit Management
* Settings
* Profile

Settings should be a standalone section, not hidden inside the profile page.

### Modal-Based Actions

Instead of displaying forms inline below content, use modal/pop-up dialogs for:

* Add Habit
* Add Goal
* Add Note
* Add Template
* Add Tracker Entry
* Add Statistics Configuration
* Calendar Events

The interface should remain clean and uncluttered.

### Habit Templates System

* Add a "View Templates" option when creating a habit.
* Users can create habits from templates.
* Once a template has been used, it should not appear again in the selection list unless manually re-enabled.
* Templates should have their own management section.

### Today Section

* Cleaner daily overview.
* Show upcoming habits by scheduled time.
* Display progress, streaks, and completion status.
* Allow quick completion actions.
* Add motivational insights and summaries.

### Habit Scheduling

Every habit should support:

* Time of day
* Start date
* Frequency
* Daily/Weekly/Monthly recurrence
* Reminder settings
* Priority level
* Category assignment

Habits should automatically appear in the Today view based on their schedule.

### Calendar Improvements

Redesign the calendar completely.

Add:

* Current date indicator
* Current time indicator
* Monthly view
* Weekly view
* Daily view
* Scheduled habits
* Goals
* Notes
* Habit completion history
* Event timeline
* Upcoming reminders

Improve layout, readability, and navigation.

### Statistics & Analytics

Allow users to configure:

* Target completion times
* Habit schedules
* Daily completion rates
* Weekly performance
* Monthly performance
* Success trends
* Streak analysis
* Consistency scores

Provide meaningful insights rather than only raw numbers.

### Habit Management Section

Create a dedicated "Manage Habits" section where users can:

* Edit habits
* Delete habits
* Archive habits
* Duplicate habits
* Change schedules
* Modify reminders

Editing and deletion should NOT happen directly from the Today view.

### Anti-Cheat System

The application should enforce an "Honest Tracking Policy."

Rules:

1. Past records become permanently locked after the day ends.
2. Users cannot modify yesterday's completion status.
3. Users cannot retroactively mark habits as completed.
4. Users cannot edit historical statistics.
5. Users cannot manipulate streak data.
6. All habit history should remain immutable once archived.
7. Maintain an audit log of changes to habits and schedules.

This ensures accountability and accurate long-term tracking.

### Notes System

### Goals System

Goals should support:

Implement any missing functionality that would logically improve a professional daily habit tracking platform, including:

Overall objective: transform the application into a professional, scalable, anti-cheat, web-first habit tracking platform with excellent UX, strong data integrity, logical workflows, and minimal unnecessary scrolling.


### Theme & Visual Comfort Improvements

Improve both Light Mode and Dark Mode for better long-term usability and eye comfort.

#### Light Mode

Current light mode is too bright and harsh on the eyes.

Requirements:

* Replace pure white backgrounds with soft off-white tones.
* Use better contrast balancing.
* Reduce visual glare during extended use.
* Create a cleaner, premium, productivity-focused appearance.
* Use subtle shadows and borders instead of strong contrasts.

#### Dark Mode

Current dark mode is too dark and visually heavy.

Requirements:

* Avoid pure black backgrounds.
* Use modern dark gray surfaces instead.
* Improve readability and visual hierarchy.
* Increase contrast between cards, panels, and backgrounds.
* Create a softer, more comfortable viewing experience for long sessions.

#### Theme System

* Implement a professional design system for both themes.
* Ensure all components work consistently across light and dark modes.
* Support automatic system theme detection.
* Add theme preview options in Settings.
* Maintain accessibility standards and proper contrast ratios.
* Ensure charts, calendars, statistics, modals, and dashboards remain visually clear in both modes.

Goal: Create balanced, premium themes that are comfortable for daily use. Light mode should not feel blinding, and dark mode should not feel like a black void. Both should feel modern, professional, and easy on the eyes during long productivity sessions.


### Onboarding

The first run should get the user to a working tracker in under a minute.

* Welcome screen with a one-line value proposition.
* Goal picker (Fitness, Study, Work, Lifestyle, Mental Health).
* Offer a matching template, or let them add a custom habit.
* Optional reminder-time preference.
* Land on the Today screen with their first habits already there.
* Do not ask for payment or unnecessary personal info up front.


### Accounts, Sync & Data

Move beyond single-device localStorage without losing the offline-first feel.

* Email and Google sign-in (Supabase Auth).
* Cloud sync so habits, marks, notes, and goals follow the user across devices.
* Offline-first: changes save locally and reconcile on reconnect, no data loss.
* Row Level Security so users can only ever read/write their own data.
* Validate all input on the server (Zod) — never trust the browser.
* Account deletion and full data export (JSON + CSV).


### Free vs Pro

Keep the free tier genuinely useful; make Pro feel like added power, not a paywall on the basics.

* Free: limited active habits, basic stats, one reminder, single device.
* Pro: unlimited habits, advanced stats, full history, notes, templates,
  multi-device sync, export, and AI insights.
* Never block the core loop (create -> mark -> see progress).
* Transparent pricing and easy cancellation.


### Reminders & Notifications

* Per-habit reminder times.
* Quiet hours and a global on/off switch.
* Helpful, not nagging ("You planned Workout today — mark it done?").
* Web push where supported; treat true OS notifications as a mobile-era feature.


### Search, Filtering & Organization

As data grows, keep it navigable.

* Global search across habits, notes, and goals.
* Filter by category, priority, status, and tag.
* Archive instead of delete to preserve history.
* Sort by schedule, priority, or recent activity.


### Performance & Reliability

* Open fast; show Today's habits immediately.
* Keep the tracker grid smooth with many habits and a long date range.
* Save changes instantly with clear success/error feedback.
* Never lose data: guard against duplicate-on-sync and partial writes.
* Graceful error states with a retry path, never a raw error code.


### Accessibility

* Meet WCAG AA contrast in both themes.
* Full keyboard navigation and visible focus states.
* Screen-reader labels on every interactive control and grid cell.
* Never rely on color alone — pair it with icons and text.
* Honor reduced-motion and large-text preferences.


### Quality Gates

Before each release, all of these must be green:

* TypeScript: 0 errors.
* ESLint: 0 errors.
* Unit tests pass (scheduling, streaks, completion, storage validation).
* Production build succeeds and every route returns 200.
* Manual pass of the core loop on mobile and desktop.


### Overall Objective

Deliver a professional, scalable, anti-cheat, web-first habit tracker with
excellent UX, strong data integrity, honest long-term tracking, and a free
tier people love before they ever consider paying. Every feature should
serve the one action that matters most: marking a habit done and coming
back tomorrow.

Track your life, one day at a time.
