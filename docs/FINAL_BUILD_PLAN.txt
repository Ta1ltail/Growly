==========================================================
 1. THE CONCEPT (one line)
==========================================================
"Excel but better" - a daily habit & task tracker where you
tap a date cell to mark a task done / missed / skipped,
organized by life categories, with streaks, statistics, goals,
notes, and a gamified progression layer (XP, levels, titles,
achievements). No ads. Free basic tier + Pro later.
Build target: WEB FIRST (mobile/desktop later).


==========================================================
 2. THE SECTIONS (full vision)
==========================================================
  1. Today        - daily page + gamified progress dashboard
                   + engagement features (check-in, quest, spin)
  2. Tracker/Grid - rows = habits, columns = dates ("Excel view")
  3. Calendar     - plan by date: month / week
  4. Habits       - create & manage habits (paginated)
  5. Categories   - Lifestyle, Workout, Studies, Work, Hobbies...
  6. Statistics   - completion %, streaks, interactive charts
  7. Goals        - bigger targets with progress bars + milestones
  8. Notes/Journal- daily notes, reasons
  9. Achievements - gallery: unlocked/locked, progress, filters
 10. Profile      - character page: level, XP, title/rank, showcase, coins
 11. Shop         - spend derived coins: cosmetics + streak-freeze
 12. Templates    - pre-made routines
 13. Settings     - theme, grace window, data tools (account later)

Bottom nav: Today . Tracker . Calendar . Stats . Profile


==========================================================
 3. THE TECH STACK
==========================================================
  -- IN USE NOW --
  Framework ........ Next.js 16.2.9 (MODIFIED - see AGENTS.md)
  Language ......... TypeScript
  Styling .......... Tailwind CSS v4 (CSS-variable theming)
  Icons ............ lucide-react
  Charts ........... hand-built SVG (TrendLineChart) - no chart lib
  Persistence ...... localStorage (schema v6) via useSyncExternalStore
  Testing .......... Vitest (81 tests)
  Hosting/Code ..... Vercel + GitHub

  -- PLANNED (Phase 4-5, all free tiers to start) --
  Database ......... Supabase (Postgres)      Login ... Supabase Auth
  DB access ........ Drizzle ORM              Security  Supabase RLS (CRITICAL)
  Validation ....... Zod                      Email ... Resend
  Payments ......... PayMongo (GCash/PH) + PayPal (intl)
  Monitoring ....... Sentry + Vercel Analytics
  E2E tests ........ Playwright               Rate limit  Upstash
  Legal ............ Privacy Policy + Terms (REQUIRED for payments)

  KEY NOTES:
   - Next.js IS the backend. No separate server needed.
   - $0/month to start; payment processors take ~2-4% only when paid.
   - Add hardening tools per phase, not all at once.

==========================================================
 5. LESSONS BAKED IN
==========================================================
  1. Start with the simple Today checklist, not the hard grid. [done]
  2. localStorage -> database is a known rework, scheduled Phase 4.
  3. Always design the DATA SHAPE before coding.
  4. Web notifications are weak -> real alerts wait for mobile.
  5. Scope creep kills projects -> ship each phase before expanding.
  6. Keep gamification DERIVED from history, never stored ->
     no cheating, no desync.
  7. Run the four gates after every part before moving on.
  8. Gates prove it compiles, not that it works - drive new
     UI in a real browser too.
  9. Local feature development can continue in parallel with cloud
     planning. Engagement features proved the app has room to grow
     before adding accounts/payments.
