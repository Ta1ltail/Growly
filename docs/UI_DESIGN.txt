This replaces the old "Data/Pro light" direction.
New direction (from sample design.PNG): DARK, MODERN, GLASSY,
electric-accent. Premium feel, lots of interaction.


==========================================================
 VISUAL STYLE  (locked)
==========================================================
  - Theme: DARK by default (deep navy-black), with LIGHT and
    SYSTEM modes the user can switch to.
  - Accent: customizable. 6 presets — Electric blue (default),
    Violet, Cyan, Emerald, Rose, Amber.
  - Surfaces: glassy cards (subtle blur + translucency), soft
    rounded corners (rounded-2xl), thin borders, gentle glow
    behind accents.
  - Motion: fade-in / rise / pop animations, hover lifts,
    active-press scale, smooth color transitions.
  - Icons: lucide-react (modern line icons) everywhere.

  COLOR TOKENS (CSS variables, swap per theme):
    --c-bg / --c-bg2 .... page background (+ accent glow)
    --c-surface ......... cards
    --c-surface2 ........ inputs / hovers
    --c-line ............ borders
    --c-ink ............. primary text
    --c-muted/--c-faint . secondary text
    --c-accent .......... brand (user-chosen)
    states: done #22c55e, missed #f43f5e, skipped #64748b


==========================================================
 LAYOUT  (responsive)
==========================================================
  DESKTOP (md+): fixed LEFT SIDEBAR (icons + labels, active
    highlight) + wide content area (max-w-5xl). No wasted space.
  MOBILE: bottom navigation bar (icon + label, active pill).
  Same 5 destinations: Today · Tracker · Calendar · Stats · Profile
  Secondary (Goals, Templates) live inside Profile.

==========================================================
 DESIGN PRINCIPLES
==========================================================
  1. Dark, calm, premium — never harsh/bright.
  2. Fast to mark — one tap, with satisfying micro-animation.
  3. Use the whole screen on desktop (sidebar + wide content).
  4. Customizable — the user owns the look (theme + accent).
  5. Consistent components everywhere (Card, PageHeader, etc.).
  6. Responsive first — works phone -> desktop.
