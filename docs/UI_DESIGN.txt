    Templates, Settings) lives inside those or in a menu.

==========================================================
 DESIGN PRINCIPLES
==========================================================
  1. Fast to mark - tapping a habit done is ONE tap.
  2. Glanceable - color tells you the state instantly.
  3. Not cluttered - show today first; details on demand.
  4. Consistent - same nav, same cards, same buttons everywhere.
  5. Mobile-first - design for phone, then widen for desktop.

==========================================================
 CHOSEN VISUAL STYLE:  DATA / PRO   (locked)
==========================================================
Direction: dense, spreadsheet-like, data-first, minimal
decoration. Power-user feel. Fits "Excel but better".

-----------------------------------------
 THEME
-----------------------------------------
  - Base: LIGHT, clean, neutral (Excel/Linear-light feel).
  - Dark mode: added later (Phase 5) as a toggle./
  - Minimal decoration: thin borders, no big shadows,
    information over ornament.

-----------------------------------------
 COLORS (hex - use these exactly)
-----------------------------------------
  Background ....... #F8FAFC  (very light grey)
  Surface/cards .... #FFFFFF  (white)
  Border/lines ..... #E2E8F0  (thin grey)
  Text primary ..... #0F172A  (near-black slate)
  Text secondary ... #64748B  (muted slate)
  Accent (brand) ... #4F46E5  (indigo - buttons, links, active nav)

  STATE COLORS (the grid cells + marks):
  Done ............. #22C55E  (green)
  Missed ........... #EF4444  (red)
  Skipped .......... #94A3B8  (grey)
  Partial .......... #F59E0B  (amber)
  Empty/none ....... #F1F5F9  (faint grey)

-----------------------------------------
 TYPOGRAPHY
-----------------------------------------
  - UI font: "Inter" (clean, modern, great for data).
  - Numbers/stats/grid: a MONOSPACE font (e.g. JetBrains Mono)
    so columns line up like a spreadsheet.
  - Sizes: small & tight. Body 14px, labels 12px, headings 16-18px.

-----------------------------------------
 DENSITY / SPACING (the "Pro" feel)
-----------------------------------------
  - Compact rows: ~32px tall in the grid.
  - Tight padding, thin 1px borders between cells.
  - Fit a LOT on screen; no wasted space.
  - Sticky header row + sticky habit-name column in the grid
    (so they stay visible while you scroll dates).

-----------------------------------------
 COMPONENTS
-----------------------------------------
  - Cells: filled with the state color, single letter or icon.
  - Buttons: small, square-ish, indigo accent for primary.
  - Cards: white, 1px border, slight 6px rounded corners.
  - Nav: highlighted with the indigo accent on the active item.

  This whole spec maps directly to Tailwind classes when we build,
  so the look stays consistent everywhere.
