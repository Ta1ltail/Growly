==========================================================
 THEME SYSTEM  (how it works)
==========================================================
  - All colors are CSS variables (--c-*). Light values live on
    :root; dark values on [data-theme="dark"]. Switching the
    attribute re-themes the whole app instantly.
  - Accent is its own variable (--c-accent), set from the
    user's chosen preset — so any accent works with any mode.
  - layout.tsx runs a tiny inline script BEFORE paint that reads
    the saved theme from localStorage and applies it -> NO flash
    of the wrong theme on load.
  - ThemeApplier (client) keeps it in sync after interaction and
    reacts to OS changes when mode = "system".


==========================================================
 DATA FLOW
==========================================================
  UI  ->  store actions (addHabit, cycleMark, setTheme, ...)
       ->  update() writes localStorage + notifies subscribers
       ->  useAppData() (useSyncExternalStore) re-renders every
           screen with the new data. One source of truth.
